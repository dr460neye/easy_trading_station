# Implementation notes (M3-M6)

- Station: `station/TradingStationBlock` (+ `TradingStationPart`, `TradingStationBlockEntity` on BACK_LOW). FACING = side the player stands on; placed cell = FRONT_LOW, BACK_LOW lies behind it. The four cells stay together via `updateShape` (like doors).
- Controls: right-click = talk/trade (the NPC's own `interact`, fallback trading then dialog). Right-click with a filled catcher = quick insert. Shift + right-click (empty hand or catcher in hand) = station menu (vanilla hopper layout, server-driven `StationMenu`/`StationContainer`): slot 1 = NPC as a filled catcher, slot 2 = workstation block; items can be put in/taken out in any order, NPC slot is locked while someone trades.
- Server sessions (`StationSessions`): on open a paused, invulnerable entity is added to the level (needed for Easy NPC screens), on menu close / logout / distance / 5 s without menu its state is written back (`serializePresetData`) and it is discarded. Entities tagged `easy_npc_trading_station:transient` that are not an active session are cancelled on load.
- Client: `client/TradingStationRenderer` caches one never-added display entity per BE (`displayEntity`, rebuilt when `version` changes) and draws the workstation block via `BlockModelResolver`.
- Variants: `StationVariant.discover()` (built-ins + `WoodType.values()` + text file `config/easy_npc_trading_station-extra-variants.txt` (mod configs are not loaded during RegisterEvent)), registered in `ModBlocks` inside `RegisterEvent`. Built-in assets: `python tools/generate_station_assets.py` (models, blockstates, loot, recipes, tag, lang) + `tools/generate_station_icons.ps1`. Other variants: `station/GeneratedStationPack` writes assets into `config/easy_npc_trading_station_generated_pack` and serves them as an always-active pack; texture is `<ns>:block/<planks path>`.
- Config: SERVER `station.defaultWorkstation`, `station.workstationDefaults`; COMMON `variants.dynamicRecipes`.
- Known limits: explosions that destroy only a back cell lose the station item (contents still drop); shape is a full cube for all parts; modded woods whose planks texture is not `block/<wood>_planks` show a missing texture; the sanitizer risk (S5.1) is unverified.
